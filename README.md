# Iber (Antigravity) — Assessment Engine & Endpoint Security Audit

**Iber** is an offline-first cybersecurity posture assessment suite engineered for small, medium, and micro enterprises (SMMEs). Operating without live external telemetry or cloud dependencies, the engine ingests local endpoint scan payloads, benchmarks host configurations against hardened software baselines, and synthesizes clear, prioritized remediation workflows.

### Core Capabilities
* **Deterministic Risk Scoring:** Benchmarks local system configurations and Attack Surface Reduction (ASR) rule implementations against strict baselines.
* **Multi-Format Reporting:** Automatically compiles audit findings into machine-readable `report.json`, interactive `report.html`, and executive-ready `action-plan.pdf` deliverables in under five seconds.
* **Offline-First Architecture:** Self-contained executable pipeline designed for zero-connectivity audit environments with an offline wheelhouse dependency cache.
* **Cross-Platform Toolchain:** Synchronized development architecture featuring a Python 3.12 core compiled via PyInstaller for Windows x64/ARM64 and cross-platform desktop shells.
